🌱 Code-Garten

Löse Codes ein und sammle Items auf deiner Rasen-Wiese. Tippe rechts am Rand auf „Code einlösen“, gib einen Code ein und schon erscheint dein Item.

Je seltener das Item, desto wertvoller: gewöhnlich selten episch legendär. Manche Items (z. B. Krone oder Haustier) trägt dein Avatar direkt.

Konzept-Demo: Die Items gehören zu diesem Mini-Spiel. Es gibt keinen Login und keine echten Käufe. Später soll das Code-System in ein Roblox-Erlebnis eingebaut werden – dieser Prototyp testet zuerst die Idee.
